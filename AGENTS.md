# Ebirone Michael — Developer Portfolio

## Project identity
Build and maintain a premium personal developer portfolio for Ebirone Michael, a Student Developer at Kings Engineering College.

## Design decisions
- Apple-inspired premium aesthetic.
- Charcoal and silver color palette.
- Professional typography, refined spacing, subtle animations, and smooth scrolling.
- Fully responsive across mobile, tablet, laptop, and desktop.
- Prioritize accessibility, performance, and maintainable code.

## Technology stack
- React
- TypeScript
- Vite
- Node.js and Express for the contact API
- Nodemailer for email delivery

## Portfolio requirements
- Professional homepage and introduction.
- Concise About section.
- Selected projects with individual case-study pages.
- Skills, education, GitHub links, and recruiter-focused contact.
- Keep unknown personal details, project results, contact information, and credentials as placeholders until verified.
- Never invent achievements or repository URLs.

## Development workflow
- Inspect existing code before making changes.
- Preserve the established visual design unless asked to redesign it.
- Make focused, maintainable changes.
- Run `npm run build` after significant frontend changes.
- Run `npm audit` when changing dependencies.
- Never use `npm audit fix --force` without reviewing the potential breaking changes.
- Test navigation, responsive layouts, project pages, and contact form behavior.
- Never expose SMTP credentials, API keys, or secrets in frontend code or Git.

## Collaboration
Explain important changes, provide commands that work on Ubuntu, and report what was tested and what still needs verification.
